# Northline Workshop Co. — vendor & purchasing ops

This repository is the internal operations hub for the Northline Workshop Co.
procurement team. It contains:

- `vendor_src/catalog_data.js` — the mirrored catalog source published by the
  SalvageWorks Depot vendor storefront, including the merchandising team's
  inline notes.
- `vendor_site/` — the static storefront mirror served at
  https://raw.githack.com/wholetherapi/filesystem_playwright_with_chunk_git_github_1-workshop-7c41/main/vendor_site/index.html
- `ops/reverify_queue.md` — the open merchandising re-verification export.
- `purchasing/` — published procurement shortlists.

Do not edit the vendor mirror or the merchandising export while a procurement
round is in progress.
